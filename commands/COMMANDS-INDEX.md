# Commands Index

This folder stores durable project context for future Codex sessions.

## Files

- `FRONTEND-CONTEXT.md`
  - installed skills, stack summary, key source files, and current app snapshot
- `ARCHITECTURE-OVERVIEW.md`
  - current architecture, strengths, risks, backend separation strategy, and target structure for scale
- `SCALING-AND-REDESIGN-PLAN.md`
  - recommended path for scaling the app and redesigning safely
- `NAVIGATION-CONTEXT.md`
  - route ownership, header/footer navigation, and future navigation architecture
- `STYLES-AND-DESIGN-SYSTEM-CONTEXT.md`
  - styling stack, token ownership, and design-system direction
- `STATE-AND-DATA-FLOW-CONTEXT.md`
  - current state usage, data-flow issues, and Supabase-ready state boundaries

## Suggested Usage

When starting a future frontend task, read these files first:

1. `commands/FRONTEND-CONTEXT.md`
2. `commands/ARCHITECTURE-OVERVIEW.md`
3. `commands/SCALING-AND-REDESIGN-PLAN.md`
4. `commands/NAVIGATION-CONTEXT.md`
5. `commands/STYLES-AND-DESIGN-SYSTEM-CONTEXT.md`
6. `commands/STATE-AND-DATA-FLOW-CONTEXT.md`

That gives the minimum shared context before making architecture or UI changes.
